# CrazyGift Premium Gifting Website

## Build
- Create a single, polished enquiry-focused website with a sticky header, mobile menu, fixed contact actions, and smooth section navigation.
- Build the complete page flow: premium opening area, audiences served, four hampers, custom branding showcase, interactive gift builder, bulk orders, process, benefits, product gallery, branded-gift story, enquiry form, clearly labeled sample feedback, FAQs, final contact prompt, and footer.
- Use the provided real phone, WhatsApp, email, Instagram, Kota delivery, minimum-order, price, and payment details throughout.

## Visual direction
- Establish a luxury black, metallic-gold, and warm-ivory design system with premium serif/sans typography, restrained motion, soft depth, and accessible contrast.
- Generate a cohesive set of realistic black/ivory/gold Diwali hamper and branded-box images because no product or logo files were uploaded.
- Keep the wordmark treatment simple and replaceable so the official logo can be dropped in later without changing the layout.

## Interactions
- Make every call and WhatsApp action functional, including product-specific prefilled messages.
- Build the custom quotation tool and enquiry form with validation and dynamically generated WhatsApp messages.
- Add an accessible FAQ accordion, keyboard-friendly mobile navigation, visible focus states, and reduced-motion support.

## Quality
- Store hamper information separately for easy editing.
- Add complete page metadata, Open Graph fields, keywords, semantic headings, descriptive image text, and local-business structured data.
- Verify desktop and mobile layouts, menus, forms, contact links, and overflow in the live preview.

## Technical note
- The project uses its existing supported React/TanStack foundation rather than replacing it with Next.js; TypeScript, Tailwind CSS, and Lucide icons remain part of the implementation.
- This version is frontend-only: enquiries open WhatsApp, personal information is not stored, and payment is shown as available without creating a payment gateway.
